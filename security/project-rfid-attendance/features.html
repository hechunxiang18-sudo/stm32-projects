功能特性

💵

RFID 刷卡签到

RC522 读取 IC 卡 UID，识别速度 <100ms，支持 ISO14443A 标准

🖨

LCD 大屏显示

128×64 点阵 LCD，显示姓名、工号、时间、签到状态

🔊

语音播报

JQ8900 语音模块，支持 MP3 播放，可定制欢迎语音

💾

USB 导出 CSV

CH340 USB 串口，一键导出考勤报表，兼容 Excel/WPS

🕓

RTC 时钟

DS3231 高精度时钟，年误差 <2 分钟，掉电保存

🗃

SD 卡备份

SPI 接口 SD 卡模块，1000 条记录本地存储 + 备份

项目概述

基于 STM32F103C8T6 的企业级智能门禁系统，支持 IC 卡刷卡开门、密码键盘验证、指纹识别三种认证方式。通过 ESP8266 WiFi 模块连接云端管理平台，管理员可远程开门、查看进出记录、授权临时密码。内置 RTC 时钟记录所有开门事件，支持防拆报警和非法闯入检测。

适用于公司、实验室、仓库等场所的门禁管理，系统响应时间 < 0.5s，支持 1000 条日志存储。

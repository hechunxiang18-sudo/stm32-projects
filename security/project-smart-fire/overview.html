项目概述

基于 STM32F103C8T6 的智能消防预警与自动灭火系统。采用多传感器融合探测技术， 同时监测火焰、烟雾、温度三项指标，通过模糊算法判断火情等级，实现分级报警和 自动灭火。支持 GSM 短信远程报警、本地声光报警、自动切断电源/燃气阀门。

适用于家庭、仓库、实验室等场所的消防监控，系统响应时间 < 2 秒，误报率 < 1%。

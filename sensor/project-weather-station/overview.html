项目概述

基于 STM32F103C8T6 的多要素户外环境监测站，集成温湿度、大气压、PM2.5/PM10、风速风向、紫外线等传感器。数据通过 LoRa 无线传输到网关，网关汇聚后经 4G 上传至云平台，支持 Web 端实时查看和历史曲线分析。内置 SD 卡本地数据备份，断网时数据不丢失。

适用于智慧城市、农业气象、校园科普等场景，IP65 防护等级，太阳能+锂电池供电，可连续工作 7 天以上。

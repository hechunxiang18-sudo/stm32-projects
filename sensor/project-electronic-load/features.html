功能特性

⚙

CC/CV/CR 模式

恒流放电 0-5A、恒压放电、恒阻放电三种模式

🔋

电池容量测试

自动计算 Ah 容量，支持锂电/镍氢/铅酸多种电池

📌

截止电压设置

可设放电截止电压，到达后自动停机保护电池

🌡

过温风扇散热

NTC 检测温度，超过 50°C 自动启动风扇 PWM 调速

📈

OLED 实时曲线

1.3 寸 OLED 显示电压/电流/功率曲线及数值

💻

USB 上位机

CH340 串口通信，PC 端实时曲线与数据导出

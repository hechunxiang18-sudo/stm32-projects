功能特性

🌬

3 挡调速

微风 30% / 中档 60% / 强风 100% 三挡切换，PWM 10kHz 无级调速

⚡

AO3400 MOS 驱动

N-MOS 管 PWM 驱动 RF-300 电机，低导通电阻 Rds(on) < 35mΩ

📼

WiFi 联网控制

ESP8266 接入 MQTT，手机 App/语音助手控制开关和挡位切换

🖨

OLED 显示

0.96 寸 OLED 显示当前挡位、百分比、电量和 WiFi 连接状态

🔄

堵转保护

电流检测判定堵转，立即停机关闭 PWM，防止电机和 MOS 过流损坏

⚡

18650 + Type-C

18650 锂电供电，TP4056 充电管理，Type-C 接口充电，电量检测

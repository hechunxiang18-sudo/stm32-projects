项目概述

基于 STM32F103C8T6 和 HLW8032 高精度电能计量芯片的智能电表系统，可精确测量交流电压 (80-260V)、电流 (0-20A)、有功功率、功率因数和累计电量。通过 ESP8266 WiFi 模块将数据 上传到 MQTT 服务器，实现手机和 Web 端实时监控。内置 20A 继电器支持过载自动断电保护， 配备 OLED 本地显示和蜂鸣器报警提示。

适用于家庭用电监测、智能配电箱、能源管理、实验室设备监控等场景。

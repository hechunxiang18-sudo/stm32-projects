项目概述

基于 STM32F103C8T6 的 WiFi 天气时钟，通过 ESP8266 连接互联网获取 NTP 网络时间自动校时， 同时从天气 API 获取实时天气和未来 3 天预报数据。DS3231 RTC 作为本地时钟备份， 断电后时间不丢失。

DHT22 采集本地温湿度，光敏电阻实现自动亮度调节。1.3 寸 OLED 展示时钟、天气、温湿度、 闹钟等信息，4 个触摸按键切换显示模式。配备蜂鸣器闹钟功能，适合桌面电子日历、家庭信息台等场景。

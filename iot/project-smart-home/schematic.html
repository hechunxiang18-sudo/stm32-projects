电路原理

  1. 传感器数据采集：DHT11 单总线协议接 PB0，BH1750 通过 I2C1 (PB6-SCL, PB7-SDA) 读取
  2. 继电器控制：4 路继电器分别由 PC0-PC3 控制，NPN 三极管驱动，高电平有效
  3. WiFi 通信：ESP8266 通过 USART2 (PA2-TX, PA3-RX) 与 STM32 通信，波特率 115200
  4. OLED 显示：I2C1 总线上挂载 OLED，地址 0x3C，刷新率 10Hz
  5. 红外遥控：VS1838B 接收头接 PB1 (外部中断)，发射管接 PB2 (PWM 载波 38kHz)
  6. 自动联动逻辑：光照 < 50 lux 自动开灯，温度 > 30°C 自动开风扇

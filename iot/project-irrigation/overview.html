项目概述

基于 STM32F103C8T6 的智能灌溉控制系统，适用于家庭花园、农田大棚等场景。8 路土壤湿度传感器 + 8 路电磁阀实现分区精准灌溉，DS18B20 监测环境温度，雨水传感器雨天自动停灌。内置自动/手动/定时三种模式，ESP8266 联网后与天气 API 联动，预报有雨时自动跳过灌溉。

系统支持手机 App 远程控制，可查看各区域湿度曲线和用水量统计。功耗优化设计，待机电流 < 30mA。
